# 할 일

순수 HTML, CSS, 자바스크립트로 만든 개인용 할 일 관리 앱입니다.
프레임워크, 라이브러리, 빌드 도구를 쓰지 않습니다.

## 실행 방법

`index.html`을 더블클릭해 브라우저로 엽니다. 설치나 서버가 필요 없습니다.

## 기능

- 할 일 추가 (Enter, 최대 100자, 공백만 있는 제목은 거부)
- 인라인 수정 (수정 버튼 또는 제목 더블클릭, Enter 저장, Esc 취소)
- 삭제 (확인 창)
- 완료 체크 (완료 항목은 취소선과 함께 목록 아래로 이동)
- 카테고리: 업무 / 개인 / 공부. 추가할 때 마지막으로 고른 카테고리가 기본값
- 자동 분류: 제목을 입력하면 키워드(회의, 장보기, 복습 등)를 보고 카테고리를 미리 골라 준다.
  직접 고르면 그 선택이 우선한다
  - [자동 재분류] 버튼으로 켜고 끈다
  - [분류 설정]에서 카테고리별 키워드를 고치거나 기본값으로 되돌린다
- 카테고리 필터 탭 (탭마다 미완료 개수 표시)
- 전체 진행률과 카테고리별 진행률
- 완료 항목 비우기
- 다크 모드: 오른쪽 위 [다크 모드]/[라이트 모드] 버튼. 직접 고르기 전에는 운영체제 설정을 따른다
- JSON 내보내기: 할 일과 분류 키워드를 `todos-YYYY-MM-DD.json` 파일로 내려받는다
- JSON 불러오기: 내보낸 파일을 골라 현재 목록을 그 내용으로 바꾼다(확인 창).
  형식이 틀린 항목은 빼고 불러온다
- 단축키: 글을 쓰는 중이 아닐 때 `/`를 누르면 할 일 입력창으로 이동
- 모든 변경 자동 저장

## 데스크톱 버전

`web_version/index.html`은 넓은 화면용 레이아웃입니다(900px 이상에서 왼쪽 사이드바 + 오른쪽 목록).
기능과 저장 데이터는 같고, 좁은 화면에서는 기본 버전과 같게 보입니다.
상위 폴더의 `app.js`와 `style.css`를 함께 쓰고, `web_version/desktop.css`에 데스크톱용 스타일만 더합니다.
그래서 `web_version` 폴더만 따로 떼어 옮기면 동작하지 않습니다.

## 파일

- `index.html` — 화면 구조
- `style.css` — 레이아웃과 스타일
- `app.js` — 상태, 저장, 렌더링, 이벤트

## 데이터 저장 위치와 한계

데이터는 브라우저의 `localStorage`에 `todo-app:v1` 키로 저장됩니다.
저장된 값이 깨져서 읽을 수 없으면 원본을 `todo-app:v1:backup` 키로 옮기고 빈 목록으로 시작합니다.

- 브라우저마다 따로 저장됩니다. Chrome에서 만든 할 일은 Edge나 Firefox에서 보이지 않고,
  다른 기기와도 동기화되지 않습니다.
- 브라우저의 사이트 데이터(쿠키 및 사이트 데이터)를 지우면 할 일도 함께 사라집니다.
- 시크릿/사생활 보호 창에서는 창을 닫으면 사라지거나 저장이 안 될 수 있습니다.
  저장에 실패하면 화면에 "저장할 수 없습니다" 안내가 나타납니다.
- `file://`로 연 페이지의 저장 공간은 브라우저에 따라 파일 위치마다 따로 잡힐 수 있습니다.
  폴더를 옮기면 이전 데이터가 보이지 않을 수 있습니다.
